# Swara website

A static page. There is no build step.

## Preview locally

```bash
python3 -m http.server -d website 8080
```

## Deploy on Vercel

Import this repository, set **Root Directory** to `website`, and set the framework preset to **Other**.
Leave the build command empty.

## About the images

The screenshots come from one screen recording of the Deck skin. The album art and song details were
replaced with placeholders. The non-Forest colour themes are recoloured previews, not captures.
